# История версий «Контакт»

## v1.0.0 — 16 ноября 2026

Первый стабильный релиз настольного приложения для учёта электроэнергии. **Приёмка владельцем завершена 16.11.2026.**

### Возможности
- Офлайн-приложение для Windows 10/11 x64 без Python, сервера, регистрации и административных прав.
- Арендаторы, архив, тарифы, помесячные расчёты, история и автоматическое сохранение показаний.
- Создание и повторная генерация актов и счетов в PDF с реквизитами, подписью, печатью и корректной кириллицей.
- Массовая выгрузка ZIP с обработкой отсутствующих/неполных расчётов.
- Интерфейс Qt, настройка размера и насыщенности текста, оригинальная иконка от владельца.
- Пользовательская SQLite-база и изображения хранятся отдельно от EXE и сохраняются при замене папки программы.

### Качество и поставка
- Windows x64 PyInstaller `onedir`; ZIP, `release-manifest.json` (SHA-256 и Git SHA), `build-requirements.txt`.
- Автоматические тесты на Windows и Ubuntu, нативные smoke-тесты собранного EXE в изолированном профиле, контроль состава ZIP.
- Все 17 сценариев PRD §6 и Windows 10/11 приняты **по подтверждению владельца**; отдельные машинные логи/номера сборок ОС не опубликованы.
- Пользовательские реквизиты, документы, реальные подписи и конфиденциальные эталоны не входят в дистрибутив.

### Установка и обновление
Скачайте `kontakt-windows-x64.zip` со страницы [GitHub Releases](https://github.com/Panika78/auto-electricity-report-service/releases/tag/v1.0.0), распакуйте и откройте `kontakt/kontakt.exe`. При обновлении заменяйте только папку программы после её закрытия; данные хранятся в `%LOCALAPPDATA%\\ElectricityReports`.

**Примечание:** сборка не подписана сертификатом Authenticode; Windows SmartScreen может выдавать предупреждение о неизвестном издателе. Версия `v1.0.0` не заявляется подписанной.
