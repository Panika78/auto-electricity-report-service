# Шрифты для PDF

PT Serif (Regular/Bold) и PT Sans (Regular/Bold) взяты из каталога Google Fonts (`ofl/ptserif` и `ofl/ptsans`). Оба семейства распространяются по SIL Open Font License 1.1. Тексты лицензий находятся в файлах `OFL-PTSerif.txt` и `OFL-PTSans.txt`.

Эти статические TTF-файлы включаются в пакет Python как данные `app.documents`; в будущей сборке PyInstaller требуется сохранить эту директорию. Шрифты не зависят от установки Windows.
